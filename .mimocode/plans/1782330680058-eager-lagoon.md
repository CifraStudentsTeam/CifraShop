# Plan: SignalR — обновления в реальном времени

## Проблема

Сейчас Admin.razor опрашивает API каждые 30 секунд (`PeriodicTimer` + `RefreshLoop`). При изменении данных на одном клиенте — другие видят изменения только через 30 сек. При 5+ вкладках админки — 5 * 7 эндпоинтов = 35 HTTP-запросов каждые 30 сек.

## Решение

SignalR Hub на сервере → мгновенная доставка уведомлений всем клиентам → удаление опроса.

### 1.3 Controllers — инжектить IHubContext и шлать уведомления

**Принцип**: после каждого успешного POST/PUT/DELETE вызывать `_hub.Clients.All.SendAsync("Notify", "entity", "action")`.

**Контроллеры для изменения** (4 шт.):

| Контроллер | Конструктор (было) | Конструктор (стало) | SendAsync после |
|---|---|---|---|
| **ProductController** | `(IProductService)` | `(IProductService, IHubContext<AdminHub>)` | create, update, batch-delete, batch-update-status |
| **OrderController** | `(IOrderService, IOrderImageRepository)` | `(IOrderService, IOrderImageRepository, IHubContext<AdminHub>)` | create-order, update-order, batch-update-status |
| **UserController** | `(IUserService)` | `(IUserService, IHubContext<AdminHub>)` | create-admin, create-student, update (PUT), delete |
| **NotificationSettingsController** | `(INotificationSettingsService)` | `(INotificationSettingsService, IHubContext<AdminHub>)` | create, update, delete |

**Формат уведомления**: `SendAsync("Notify", entity, action)`
- `entity`: `"product"`, `"order"`, `"user"`, `"notification"`
- `action`: `"created"`, `"updated"`, `"deleted"`, `"batch-updated"`

**Пример** (ProductController.Create):
```csharp
private readonly IHubContext<AdminHub> _hub;

public ProductController(IProductService productService, IHubContext<AdminHub> hub)
{
    _productService = productService;
    _hub = hub;
}

[HttpPost("create-product")]
public async Task<IActionResult> Create([FromBody] CreateProductRequest request)
{
    // ... существующая логика ...
    await _hub.Clients.All.SendAsync("Notify", "product", "created");
    return Ok(ToResponseWithUrl(product));
}
```

**Важно**: `SendAsync` вызывается ПОСЛЕ успешного сохранения в БД, но ДО возврата ответа клиенту. Это гарантирует, что уведомление приходит только при реальном изменении.

**Эндпоинты, требующие SendAsync**:

ProductController:
- `POST create-product` → `("product", "created")`
- `PUT update-product` → `("product", "updated")`
- `POST batch-delete` → `("product", "deleted")`
- `POST batch-update-status` → `("product", "updated")`

OrderController:
- `POST create-order` → `("order", "created")`
- `PUT update-order` → `("order", "updated")`
- `POST batch-update-status` → `("order", "updated")`

UserController:
- `POST create-admin` → `("user", "created")`
- `POST create-student` → `("user", "created")`
- `PUT id=` → `("user", "updated")`
- `DELETE id=` → `("user", "deleted")`

NotificationSettingsController:
- `POST` → `("notification", "updated")`
- `PUT id=` → `("notification", "updated")`
- `DELETE id=` → `("notification", "updated")`

**Не требуют SendAsync** (読み取り専用 или внутренние):
- Все `GET` эндпоинты
- `POST AdminAction` — история действий, обновляется локально через `LogAction`

### 2.2 Создать Services/SignalRService.cs

```csharp
using Microsoft.AspNetCore.SignalR.Client;

namespace CifraShop.Client.Services;

public class SignalRService : IAsyncDisposable
{
    private HubConnection? _connection;
    private readonly string _hubUrl;

    public event Action<string, string>? OnNotify;
    public bool IsConnected => _connection?.State == HubConnectionState.Connected;

    public SignalRService(string hubUrl = "http://localhost:5000/hubs/admin")
    {
        _hubUrl = hubUrl;
    }

    public async Task StartAsync()
    {
        _connection = new HubConnectionBuilder()
            .WithUrl(_hubUrl)
            .WithAutomaticReconnect(new[] { TimeSpan.Zero, TimeSpan.FromSeconds(2), TimeSpan.FromSeconds(5), TimeSpan.FromSeconds(10) })
            .Build();

        _connection.On<string, string>("Notify", (entity, action) =>
        {
            OnNotify?.Invoke(entity, action);
        });

        _connection.Reconnecting += _ =>
        {
            Console.WriteLine("[SignalR] Переподключение...");
            return Task.CompletedTask;
        };

        _connection.Reconnected += _ =>
        {
            Console.WriteLine("[SignalR] Подключено");
            return Task.CompletedTask;
        };

        _connection.Closed += async _ =>
        {
            Console.WriteLine("[SignalR] Соединение закрыто. Переподключение через 5 сек...");
            await Task.Delay(5000);
            try { await StartAsync(); } catch { }
        };

        await _connection.StartAsync();
    }

    public async ValueTask DisposeAsync()
    {
        if (_connection != null)
        {
            _connection.OnNotify -= ???; // Нет такого — нужно отписаться
            await _connection.DisposeAsync();
        }
    }
}
```

## Шаг 3: Admin.razor — замена RefreshLoop на SignalR

### 3.1 Убрать RefreshLoop и PeriodicTimer

**Удалить** из Admin.razor:

### 3.2 Добавить SignalR подписку

**Добавить** в Admin.razor:

```csharp
@inject SignalRService SignalR

// В @code:
protected override async Task OnInitializedAsync()
{
    RestoreFiltersFromUrl();
    await LoadAllData();
    await LoadHistory();

    // Подключаем SignalR вместо RefreshLoop
    SignalR.OnNotify += HandleSignalRNotify;
    try { await SignalR.StartAsync(); }
    catch (Exception ex) { ShowNotification($"SignalR: {ex.Message}", "warning"); }
}

private void HandleSignalRNotify(string entity, string action)
{
    _ = InvokeAsync(async () =>
    {
        switch (entity)
        {
            case "product":
                await LoadProducts();
                await LoadMetrics();
                await LoadAllProducts();
                break;
            case "order":
                await LoadOrders();
                await LoadMetrics();
                break;
            case "user":
                await LoadUsers();
                await LoadUsersMetrics();
                break;
            case "notification":
                await LoadNotificationSettings();
                break;
        }
        _lastUpdated = DateTime.Now;
        StateHasChanged();
    });
}

public void Dispose()
{
    SignalR.OnNotify -= HandleSignalRNotify;
    _productSearchCts?.Cancel(); _productSearchCts?.Dispose();
    _orderSearchCts?.Cancel(); _orderSearchCts?.Dispose();
    _userSearchCts?.Cancel(); _userSearchCts?.Dispose();
    _notificationCts?.Cancel(); _notificationCts?.Dispose();
}
```

### 3.3 Что происходит при каждом событии

| Событие | Какие Load* вызываются | Зачем |
|---------|----------------------|-------|
| `("product", "created")` | `LoadProducts` + `LoadMetrics` + `LoadAllProducts` | Новый товар в списке + метрики + обновить кэш для заказов |
| `("product", "updated")` | `LoadProducts` + `LoadMetrics` | Статус/количество/цена могли измениться |
| `("product", "deleted")` | `LoadProducts` + `LoadMetrics` | Товар удалён из списка |
| `("order", "created")` | `LoadOrders` + `LoadMetrics` | Новый заказ + выручка |
| `("order", "updated")` | `LoadOrders` + `LoadMetrics` | Статус заказа + выручка |
| `("user", "created")` | `LoadUsers` + `LoadUsersMetrics` | Новый пользователь + кол-во админов |
| `("user", "updated")` | `LoadUsers` + `LoadUsersMetrics` | Баланс/роль могли измениться |
| `("user", "deleted")` | `LoadUsers` + `LoadUsersMetrics` | Пользователь удалён |
| `("notification", "updated")` | `LoadNotificationSettings` | Настройки филиалов |

## Шаг 4: Fallback — таймер на 5 минут

На случай если SignalR отвалился и не переподключился. Не опрос каждые 30 сек, а раз в 5 минут как запасной вариант:

```csharp
private PeriodicTimer? _fallbackTimer;

// В OnInitializedAsync после SignalR:
_fallbackTimer = new PeriodicTimer(TimeSpan.FromMinutes(5));
_ = FallbackLoop();

private async Task FallbackLoop()
{
    while (_fallbackTimer is not null && await _fallbackTimer.WaitForNextTickAsync())
    {
        try
        {
            if (SignalR.IsConnected) continue; // SignalR работает — пропускаем
            await LoadAllData();
            await InvokeAsync(StateHasChanged);
        }
        catch { }
    }
}
```

В Dispose:
```csharp
_fallbackTimer?.Dispose();
```
